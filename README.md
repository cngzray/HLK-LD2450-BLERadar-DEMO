# HLK-LD2450-BLERadar-DEMO
ESP32 + HLK-LD2450 24G毫米波雷达 BLE 蓝牙透传 Demo
> 基于ESP32实现 LD2450 多目标人体跟踪雷达数据读取、解析，并通过 BLE 蓝牙实时上报目标坐标、距离、速度信息；串口同时输出调试日志。

## 📖 项目简介
**HLK-LD2450** 是海凌科 24GHz FMCW 毫米波雷达模组，支持最多3个运动目标同时定位跟踪，输出目标的X/Y坐标、直线距离、径向速度，探测距离最大6米，适合室内人体追踪、智能照明、安防、人体轨迹检测场景。

本Demo使用 **ESP32** 作为主控：
1. 通过 **BLE蓝牙服务** 接收 LD2450 原始雷达帧；
2. 完成帧同步、校验、解析，提取最多3个目标的位置与速度；
3. 内置简单目标有效性过滤；

> 适用硬件：ESP32-WROOM / ESP32-S系列；雷达模组 HLK-LD2450。

## 🧠 代码运行逻辑（src/main.cpp）
### 整体架构
采用 `setup()` 初始化 + `loop()` 轮询模式，非阻塞串口帧解析，BLE后台广播与特征值通知。
```
系统启动
  ↓
setup()
├─ 初始化串口（调试串口 + 雷达UART2）
├─ 初始化BLE服务、特征值，启动蓝牙广播
└─ 初始化雷达协议解析器
  ↓
loop() 循环
├─ 非阻塞读取UART2雷达字节流
├─ 帧同步：寻找帧头 AA FF + 帧尾 55 CC
├─ 完整帧校验，解析3个目标数据块
├─ 目标有效性判断（valid标记）
├─ 数据打包：X,Y,距离,速度
├─ 串口打印目标信息
└─ BLE Notify 推送雷达数据包给蓝牙客户端
```

### main.cpp 核心运行要点
1. **非阻塞串口读取**：不使用 `Serial.readStringUntil` 这种阻塞函数，避免BLE任务卡顿；
2. **帧头帧尾定界**：AA FF 作为起始标记，55 CC结束，是LD2450官方帧封装；
3. 最多3目标结构体：`valid` 标记目标是否存在；x/y单位毫米，速度cm/s；
4. BLE采用Notify，不需要客户端主动轮询，实时推送；
5. 雷达库解耦：雷达协议解析逻辑封装在LD2450库，main只负责调度、BLE、串口输出。


### 1. 串口帧协议解析逻辑
LD2450 原始帧格式：
`AA FF [Payload] 55 CC`
Payload内包含最多3个目标，每个目标8字节：
- X坐标(int16，单位mm，正负代表左右)
- Y坐标(int16，单位mm，代表距离雷达纵深)
- 距离(int16，mm)
- 速度(int16，cm/s；正数远离雷达，负数靠近雷达)

**解析算法流程**
1. 逐字节读取UART缓冲区，滑动窗口查找帧头 `0xAA,0xFF`；
2. 持续接收直到检测帧尾 `0x55,0xCC`；
3. 校验帧长度合法性；
4. 按小端序解析 int16 坐标，处理符号位；
5. 循环提取 Target0 / Target1 / Target2；
6. 无效目标标记 `valid=false`，上层直接跳过。

> 雷达模组原生输出约10帧/秒。

### 2. 目标过滤（典型算法逻辑）
内置基础有效性判断：
- 坐标超出雷达量程范围 → 标记无效；
- 目标数据全0视为无目标；
- 过滤异常跳变野点（简单阈值过滤，可自行增强滤波）；
> 可选扩展：卡尔曼滤波、轨迹平滑、目标ID关联，解决目标闪烁、跳变。

### 3. BLE 蓝牙通信逻辑
- 创建BLE Service + Characteristic，开启Notify通知；
- ESP32通过BLE连接雷达后自动订阅特征值；
- 雷达每解析一帧有效目标，打包为二进制/JSON短包，通过Notify推送；

## 📡 BLE 通信协议
BLE Service UUID / Characteristic UUID 在main.cpp宏定义内，可自行修改。
数据包示例（二进制包）：
```
target_count | t0_x | t0_y | t0_dist | t0_speed | t1_x | t1_y ...
```

## ✨ 功能扩展建议
1. **轨迹平滑滤波**：增加卡尔曼滤波/滑动平均，减少毫米波雷达点云闪烁；
2. **目标ID跟踪**：增加帧间目标匹配，维持同一个人的ID连续，避免ID跳变；
3. **区域入侵检测**：设置警戒矩形/扇形区域，目标进入触发报警；
4. **继电器输出联动**：检测到人后IO输出，控制灯光；
5. **Wi-Fi MQTT上报**：增加MQTT推送到HomeAssistant；
6. **雷达参数配置**：通过串口下发指令修改LD2450灵敏度、探测距离阈值。
